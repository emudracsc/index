# ⚡ Universal Table Copy & Excel Exporter
### (कोणत्याही HTML वेब पेजवरील टेबल १-क्लिकमध्ये कॉपी व एक्सेल एक्सपोर्ट)

हे Google Chrome Extension **इंटरनेटवरील कोणत्याही वेबसाईटवरील** (किंवा तुमच्या कॉम्प्युटरवरील कोणत्याही HTML पेजवरील) टेबल **एका क्लिकमध्ये कॉपी करून थेट Excel मध्ये पेस्ट (`Ctrl+V`) करण्यासाठी** किंवा **`.xlsx` / `.csv` फाईलमध्ये सेव्ह करण्यासाठी** बनवले आहे.

---

## 🔥 १-क्लिक कॉपी करण्याचे ३ सुपरफास्ट मार्ग:

### मार्ग १: `Alt + Click` (सर्वात वेगवान - १ सेकंदात!)
1. कोणत्याही वेब पेजवर टेबलवर जा.
2. कीबोर्डवरील **`Alt`** की दाबून धरून टेबलवर **क्लिक (Click)** करा.
3. टेबल लगेच क्लिपबोर्डवर कॉपी होते!
4. आता तुमच्या **Excel शीटमध्ये जाऊन फक्त `Ctrl + V` (Paste)** दाबा. संपूर्ण टेबल कॉलम्स आणि ओळींसह अचूक पेस्ट होईल!

---

### मार्ग २: टेबलवर राईट-क्लिक (Right Click) करा
1. कोणत्याही टेबलवर माउसचे **Right Click (उजवे क्लिक)** करा.
2. मेनूमध्ये पर्याय दिसतील:
   - **`📋 टेबल कॉपी करा (Copy Table to Excel)`**
   - **`📊 एक्सेल डाऊनलोड करा (.xlsx)`**
   - **`📄 CSV डाऊनलोड करा (.csv)`**

---

### मार्ग ३: टेबलवरील फ्लोटिंग बार (Hover Bar)
1. माऊस कोणत्याही टेबलवर नेताच टेबलच्या वर उजव्या कोपऱ्यात फ्लोटिंग बार दिसेल:
   - **`[ 📋 १-क्लिक कॉपी (Copy) ]`**
   - **`[ 📊 Excel (.xlsx) ]`**
   - **`[ 📄 CSV ]`**
2. फक्त बटनावर क्लिक करा आणि काम पूर्ण!

---

### मार्ग ४: क्रोम टूलबारमधील आयकॉन (Popup Menu)
1. क्रोमच्या वर उजवीकडे एक्स्टेंशन चिन्हावर (🧩) क्लिक करून **Universal Table Exporter** ला पिन (📌) करा.
2. आयकॉनवर क्लिक केल्यावर:
   - **`🎯 पानावरील टेबल निवडा (Pick Table)`**: यावर क्लिक करून पानावरील कोणत्याही टेबलवर पॉईंटर नेऊन क्लिक करा — टेबल लगेच कॉपी होईल!
   - **`📊 सर्व टेबल्स एकाच फाईलमध्ये (.xlsx)`**: पानात ५-१० टेबल्स असतील तरी सर्व टेबल्स एकाच फाईलमध्ये वेगवेगळ्या शीटवर डाऊनलोड होतात.
