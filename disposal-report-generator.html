Sheet4 data (Logical Discrepancies / No Mapping)
Report मधील 'Logical Discrepancies' व 'No Mapping' हे Sheet4 मधून येतात. file मधील data आधीच भरलेला आहे; तो बदलायचा असेल तरच इथे Sheet4 paste करा (Sheet4 चे A–N columns) किंवा ३ columns: Part No, Logical Error, No Mapping.
